## 📸 Capture Guide

1. Start your local environment:
   - Backend: `python main.py` (port 8000)
   - Frontend: `npm run dev` (port 3000)
2. Open your browser in fullscreen mode at [http://localhost:3000/](http://localhost:3000/).
3. Use a screenshot tool (like Windows Snipping Tool `Win + Shift + S`) to capture the clean layout.
4. Save the captured images directly to this directory using their respective names:
   - `dashboard.png`
   - `recommendation.png`
   - `workflow.png`
   - `booking.png`
   - `escalation.png`
   - `future_scope.png`
